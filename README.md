# Cyber Rescue - Python Adventure Game

## About This Project
Cyber Rescue is a text-based adventure game I created while learning Python in my programming course. Players explore different rooms, collect six important tools, and try to defeat the challenge without running into Shadow, the villain.

This project helped me practice Python programming and understand how to create a complete game using different programming concepts.

## How to Play
1. Download or open the `text_based_game.py` file.
2. Run the file using Python.
3. The game starts in the Lobby.
4. Use commands like `go north`, `go south`, `go east`, and `go west` to move between rooms.
5. Type `get` followed by an item name to collect an item.
6. Collect all six tools before entering the Server Room and confronting Shadow.

## Game Features
- Multiple rooms to explore
- Six collectible tools
- An inventory system
- A villain named Shadow
- Movement and item collection commands
- Win and lose conditions

## Python Skills Used
- Dictionaries
- While loops
- If/else statements
- Functions
- User input and validation
- Lists and inventory management
- Problem-solving and debugging

## What I Learned
Creating Cyber Rescue was one of my biggest challenges while learning Python. At first, putting all the different parts of the game together was confusing. I had to figure out how to make the rooms connect, track the player's inventory, and make sure the game responded correctly to commands.

After testing my code and fixing mistakes, I became more confident in my programming skills. This project showed me that I can take a big problem, break it into smaller steps, and create a working program.
